Computer vision · Applied ML

FitSense · AI Fitness Trainer

A live workout coach for squats, bicep curls, planks, and lunges. MediaPipe extracts pose landmarks; saved scikit-learn models classify exercise states and form errors. The Streamlit dashboard displays an annotated pose, repetition count, confidence, and corrective guidance, with FastAPI endpoints for image inference and model metrics.

Reported evaluation: accuracy of 99.41% for squat, 97.19% for bicep curl, 99.58% for plank, and 97.20% for lunge error classification, as documented in the project README. These are model evaluation results, not a guarantee of real-world performance.

Generative AI · RAG

InsureLens AI / PolicyOps AI

A policy question-answering system with separate user and admin portals. Admins upload policy PDFs and rebuild the retrieval index; users ask questions and receive answers grounded in retrieved policy clauses. The pipeline chunks documents, generates local Sentence Transformers embeddings, and syncs vectors to Pinecone.

Groq is the default LLM provider, Gemini is available as an alternative, and an extractive answer path remains available when no LLM key is configured. Upload deduplication, chunk deduplication, and configurable runtime settings are included.

Android · Background systems

Smart App Logger

An Android monitoring application that records foreground app usage and call-log changes. A foreground service and WorkManager workers support background operation; usage events are logged with durations, and the UI offers live updates and date filters.

Logs are stored locally and can be uploaded to Dropbox. The application requests system permissions explicitly and makes monitoring user-controlled; sensitive device data should only be collected with clear consent.
